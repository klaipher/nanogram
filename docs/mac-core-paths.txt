# Paths shared by the iOS and macOS Nanogram apps, and the parity rules around them.
# Identical in both repos (nanogram-ios/docs and nanogram-macos/docs); checked by tools/dev/parity/parity.py.
# Paths are relative to the core repo root (the iOS `main` layout). The Mac keeps the core in the
# submodule named by `core`.
#
# Directives
#   core <path>             Mac superproject path of the core submodule
#   core-root <sha>         the only history root a core commit may have (the history-free import)
#   repo-root ios <sha>     the only history root the iOS repo may have
#   mode legacy|shared      legacy while the Mac pins mac/core (ancestry, lag and file checks only warn);
#                           shared once the Mac pins iOS main or mac/core-lts (phase 3 flips it)
#   reference <ref>         where the pin must be an ancestor of, inside the core checkout
#   lts-ref <ref>           the history-free LTS branch used while iOS main is ahead of the Mac UI
#   lag commits=N days=N block-from=DATE   limit for shared-path commits on the reference that the pin lacks;
#                           warning until block-from, then an error
#   pin <name> ios=<path in the iOS repo> mac=<path in the Mac repo> [android=<path in the Android repo>] [external] [warn-until=DATE]
#   lib <name> [ios=<path>] [mac=<path>] [android=<path>]   a library whose single pin lives in shared/shared-libraries.json
#   share <path>            a shared path inside the core
#   allow core <path-prefix> [until=DATE] | reason   an intended difference in the core, with its reason
#   mirror ios=<file> mac=<file> [warn-until=DATE]   a file kept as an identical copy in both repos (blob ids are
#                           compared on every check: an error on the Mac side, a warning on the iOS side)
#
# Process: a fix to anything listed under `share` is committed to iOS main first; the same day run
# tools/dev/tg core-bump on the Mac (or cherry-pick -x into mac/core-lts). Mac-only code in shared
# modules stays behind #if os(macOS) or in Mac-only files and gets an `allow core` line here.
